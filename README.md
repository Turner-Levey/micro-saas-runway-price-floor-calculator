# Micro-SaaS Runway Price Floor Calculator

Free browser-only calculator for estimating a micro-SaaS monthly price floor, break-even customer count, margin gap, and runway pressure from customer count, churn, gross margin, overhead, founder income target, growth budget, and cash reserve.

Live site: https://micro-saas-runway-price-floor-calculator.vercel.app/
Tiny Tool Town listing: https://www.tinytooltown.com/tools/micro-saas-runway-price-floor-calculator/
No-Login Tools listing (pending review): https://nologin.tools/tool/micro-saas-runway-price-floor-calculator-vercel-app/
No-Login Tools badge (pending verification): https://nologin.tools/badge/micro-saas-runway-price-floor-calculator-vercel-app/

## What It Does

- Estimates the monthly ARPA needed to cover fixed overhead, founder income, and growth budget after churn and gross margin.
- Compares the current ARPA against the estimated price floor.
- Estimates break-even customer count at the current ARPA.
- Estimates runway months when the entered cash reserve is used to cover the current monthly gap.
- Generates a local Markdown note and CSV export.

## Privacy

The tool has no signup, no cookies, no analytics, no tracking beacons, no external scripts, no uploads, no runtime API calls, and no browser storage. It runs in the browser and exports local files only.
